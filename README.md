An interactive Bubble Game built using HTML, CSS, and JavaScript.

## ✨ Features

- Dynamic bubble generation
- Random hit number generation
- Real-time score update
- Countdown timer
- Event delegation
- Event bubbling
- Responsive design
- Modern user interface
- Gradient effects
- Smooth animations

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
